## What SecurityVault does

SecurityVault gives security and engineering teams one defensible view of application and cloud risk. It orchestrates native and open-source scanners, correlates their results on a single graph from repository to workload, ranks risk by reachability and exposure, routes each finding to its owner, and evaluates compliance controls from the same evidence. Release gates fail closed, control decisions are signed, and every disposition is a human decision with a reason code.

| Capability | What it covers |
|---|---|
| [SAST](https://securityvault.io/sast) | Native per-language taint engines plus the open-source tools for each language |
| [SCA & SBOM](https://securityvault.io/sca-sbom) | Dependencies, known vulnerabilities, licences, CycloneDX and SPDX bills of materials |
| [Secrets detection](https://securityvault.io/secrets-detection) | Credentials in git history and image layers, routed to an owner and tracked to rotation |
| [IaC security](https://securityvault.io/iac-security) | Terraform, CloudFormation, Kubernetes and Helm checked before apply |
| [Container security](https://securityvault.io/container-security) | Image scanning by digest, layer attribution, workload binding |
| [DAST](https://securityvault.io/dast) | Dynamic testing of running applications on the same graph as the code behind them |
| [Cloud posture (CSPM)](https://securityvault.io/cloud-posture) | Misconfigurations connected to identities, resources and workloads |
| [Identity and entitlements (CIEM)](https://securityvault.io/identity-entitlements) | Human, workload and cloud identities on the same attack paths |
| [Deployment gates](https://securityvault.io/deployment-gates) | Policy-as-code CI/CD gates using Open Policy Agent; fail closed and recorded |
| [Continuous compliance](https://securityvault.io/continuous-compliance) | Control status re-evaluated from scan evidence, with a read-only auditor portal |

## Principles

- **Fail closed.** A policy evaluation error is a deny, never a warning.
- **Scanners are untrusted.** Every tool runs as an isolated, ephemeral job with no platform credentials.
- **Humans decide.** Finding disposition is a human action with a reason code; automation never overwrites it.
- **Evidence over screenshots.** Compliance status is derived from scan evidence and signed decisions.
